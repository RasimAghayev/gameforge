# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | :white_check_mark: |

## Reporting a vulnerability

Please do **not** file a public issue for security vulnerabilities. Instead, use GitHub private vulnerability reporting (Security Advisories) or email the maintainer at rasimaqayev@gmail.com.

## Scope

Code, CI/CD pipelines, Docker images, dependencies, and secrets.

## Response timeline

- P0 (critical): acknowledged immediately, fix within 24 h.
- P1 (high): acknowledged within 24 h, fix within 72 h.
- P2 (medium): acknowledged within 3 days, fix within 7 days.
- P3 (low): acknowledged within 7 days, fix on a best-effort basis.

## Coordinated disclosure

After a report: acknowledge → triage → fix → coordinated disclosure → rotate any exposed secrets.
